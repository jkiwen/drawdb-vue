Filter: All Files Submit Search Enter a Key Group Definition You use the Definition tab in the Key Group Editor to enter a definition for a selected key group. In a logical/physical model, or when you derive a physical model from a logical model, the definition migrates to the physical side as an index comment. To enter a key group definition Right-click the entity that contains the key group for which you want to enter a definition and click Key Group Properties. The Key Group Editor opens. Select the key group in the Navigation Grid for which you want to enter a definition and click the Definition tab. Enter definition text. You can use the options on the toolbar to cut, copy, or paste text, open the text editor, or check spelling. Click Close. Definition text is saved and the Key Group Editor closes.
