Filter: All Files Submit Search Comparison of Logical and Physical Model Objects Most of the objects in the logical model correspond to a related object in the physical model. For example, the logical model contains entities, attributes, and key groups, which are represented in the physical model as tables, columns, and indexes, respectively.
