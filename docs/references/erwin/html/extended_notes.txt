Filter: All Files Submit Search The Extended Notes Tab Click the Extended Notes tab and work with the following options: Tab Property Description Additional properties Extended Notes Transfer Transfers notes to the Notes tab To transfer a note, select the Transfer check box of the note you want to transfer and then click . When you transfer a note from the Extended Notes tab to the Notes tab, the transfer process deletes the Name, Importance, and Status information. It also deletes the value in the Event field and displays "User Note". Name Specifies the name of the extended note Event Displays the extended events that you have selected to track for the model or object Status Specifies the inheritance status of the selected note - overridden or inherited This option is available only in the Column Editor dialog. Comments Displays the user's note. Click to add comments. Migrate Migrates the extended note from a parent table to the child table. For example, in a table named User, you have added a note to the column User_ID and selected the Migrate check box. When you use User_ID as a foreign key in another table, the note is displayed. This column is available only in the Column Editor and Domain Editor dialogs. Modified By Displays the name of the user that modified the extended note Importance Specifies the importance that you would like to provide to the extended note Note Status Specifies the status of the extended note Date Modified Specifies the date and time of the modified extended note The properties available on this tab differ according to the object you are viewing.
