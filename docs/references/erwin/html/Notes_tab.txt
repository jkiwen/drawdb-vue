Filter: All Files Submit Search The Notes Tab Click the Notes tab and work with the following options: Tab Property Description Additional Information Notes Transfer Transfers note to the Extended Notes tab To transfer a note, select the Transfer check box of the note you want to transfer and then click . When you transfer a note from the Notes tab to the Extended Notes tab, the transfer process deletes the values in the Created By and Modified By fields and displays the current user name in the Author field. Additionally, the transfer process deletes the value in the Event field. Event Displays the note events that you have selected to track for the model or object Status Specifies the inheritance status of the selected note - overridden or inherited This option is available only in the Column Editor dialog. Comment Displays the comment that is entered in the Notes tab. Click to add or edit comments. Migrate Migrates the note from the parent column if this check box is selected in the parent column. For example, suppose in a table named User, you have added a note to the column User_ID and you have selected the Migrate check box. When you use User_ID as a foreign key in another table, the note is displayed. This option is available only in the Column Editor and Domain Editor dialogs Date Created Displays the date and time of the created note Created By Displays the name of the user that created the note Date Modified Displays the date and time of the modified note Modified By Displays the name of the user who modified the note The properties available on this tab differ according to the object you are viewing.
